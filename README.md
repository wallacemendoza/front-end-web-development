# Front-End Web Development - Florida Tourism Website

## Overview
This repository contains a professionally redesigned, modern Florida tourism website showcasing advanced front-end development skills. The project features a complete multi-page website with responsive design, smooth animations, and a sophisticated user interface built with HTML5, CSS3, and vanilla JavaScript.

## 🎨 Design Features
- **Modern, Professional Aesthetic** - Clean, contemporary design that stands out
- **Elegant Typography** - Custom font pairing with Playfair Display (serif) and Manrope (sans-serif)
- **Florida Brand Colors** - Orange and blue gradient themes maintaining Sunshine State identity
- **Smooth Animations** - Scroll-triggered animations, hover effects, and micro-interactions
- **Fully Responsive** - Optimized layouts for desktop, tablet, and mobile devices
- **Accessibility** - Semantic HTML, ARIA labels, and keyboard navigation support

## 🛠️ Technologies Used
- **HTML5** - Semantic markup and modern web standards
- **CSS3** - Advanced styling with CSS Variables, Flexbox, and Grid
- **JavaScript (ES6+)** - Interactive features and form validation
- **Google Fonts** - Playfair Display & Manrope typography
- **Responsive Design** - Mobile-first approach with breakpoints
- **CSS Animations** - Keyframe animations and transitions
- **Intersection Observer API** - Scroll-triggered animations

## 💻 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/wallacemendoza/front-end-web-development.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd front-end-web-development
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser
   - No build tools or dependencies required
   - Works with all modern browsers

4. **Optional: Use a local server**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   ```
